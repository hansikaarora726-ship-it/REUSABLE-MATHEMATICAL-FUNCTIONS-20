## About the Project
This project is designed to perform five basic mathematical operations using reusable functions.

Users can enter two numbers and calculate different mathematical results.

## Features
- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Square of the first number
- User input functionality
- Division by zero error handling

## Technologies Used
- HTML
- CSS
- JavaScript
- Java

## Project Files
- index.html – Main webpage with HTML, CSS and JavaScript.
- mathUtils.js – Contains five reusable JavaScript functions.
- script.js – Demonstrates the use of JavaScript utility functions in Node.js.
- MathUtility.java – Contains mathematical functions using Java.
- README.md – Project documentation.

## How to Run

### HTML Version
1. Open index.html in VS Code.
2. Right-click and select Open with Live Server.
3. Enter two numbers.
4. Click the Calculate button to see the results.

### Java Version
1. Open the VS Code terminal.
2. Compile the file:
   javac MathUtility.java
3. Run the program:
   java MathUtility

### JavaScript Version
Run the following command in the terminal:

    node script.js

## Output
The program displays the results of all five mathematical operations.
